# Placeholders

Some values in this repository are environment-specific and were replaced with placeholders.
Replace them with your own values before installing.

| Placeholder | Replace with |
|---|---|
| `user` | your user name |
| `workstation` | hostname of your main workstation |
| `private-project-N` — a private companion project of the original author; not part of this repository | ×2 |
| fake address of the same kind (`100.96.0.x` Tailscale, `192.168.255.x` LAN, `192.0.2.x` other) — use your own host/Tailscale IP | ×1 |
| locally-administered fake MAC `02:00:00:00:XX:XX` — use your device's address (e.g. `bluetoothctl devices`) | ×83 |
